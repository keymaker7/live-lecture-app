# 슬라이드 연수 (Live Lecture)

실시간 슬라이드 연수 플랫폼 — Vercel 배포용 Next.js 앱.
슬라이드 + 참가자 폰(QR) + 캐릭터 광장 + 게임(퀴즈·가위바위보·달리기) + 점수·순위.

**배포 주소:** https://live-lecture-n1yt3352b-jkeymaker-5915s-projects.vercel.app

> **무료 플랜 기준 참가자 60명까지 권장.** 넘으면 발표 화면 위쪽 인원 숫자가 주황색이 됩니다.
> 실시간 서버(Supabase 무료)는 초당 메시지 100건이 한도인데, 80명 시험에서 투표를 여는 순간 등에 넘었습니다.
> 그보다 큰 연수는 Supabase Pro(초당 500건)를 검토하세요.

> **새로 배포한 뒤 첫 연수:** 시작 전에 참가자에게 **"폰 새로고침 한 번"** 을 안내하세요.
> 예전 화면이 남아 있는 폰은 새 기능(게임·순위·사칭 방지)과 맞지 않을 수 있습니다.
> 발표 화면에도 새 버전을 처음 열 때 한 번 이 안내가 뜹니다.

## 발표자 사용법

1. 첫 화면에서 슬라이드 주소(구글 슬라이드·캔바 등)와 제목을 넣고 **연수 만들기**.
2. 오른쪽 **QR** 을 참가자가 찍으면 닉네임 → 캐릭터(동물 50종, 건너뛰면 닉네임으로 자동)를 골라 들어옵니다.
3. 위쪽 버튼
   - **🚶 산책로**: 슬라이드 아래 띠에 캐릭터가 걸어 다님(기본). **띠 숨기기**로 끌 수 있음.
   - **🌳 광장**: 화면 전체가 광장. 채팅은 머리 위 말풍선, 질문은 ❓.
   - **🔊 효과음 / 🎵 음악**: 이 PC 에 기억됩니다.
   - **🏆 종합 순위**: 지금까지 끝난 게임 누적 TOP 10. 연 뒤로 1·2·3등은 광장에서 왕관·메달을 답니다.
4. 아래 **🛠 도구** → 투표·질문·타이머·영상·**🎮 게임** 탭.
5. 게임을 시작하면 화면이 광장(게임 화면)으로 바뀌고 QR 패널이 접힙니다. 화면 아래 버튼으로 진행하고, 끝나면 **닫기**.
6. 연수가 끝나면 게임 탭의 **📊 결과 내보내기** → `참가자별.csv`, `게임별.csv` (엑셀에서 바로 열림).

### 다른 PC 에서 이어서 진행

게임 탭 **🔑 발표자 링크 복사** → 다른 PC 에서 그 링크를 열면 그 PC 가 발표자가 됩니다.
링크에는 발표자 비밀값이 들어 있으니 **참가자에게 보내지 마세요.** (결과 DB 저장이 켜져 있으면 종합 순위도 복원됩니다.)
같은 연수를 두 창에서 열면 뒤에 연 창에 "이미 다른 창에서 진행 중 — [여기서 진행]"이 뜹니다.

## 게임

| 게임 | 진행 | 점수(기본) |
|---|---|---|
| 퀴즈 OX·객관식 | 문제 공개 → (제한 시간·지금 마감) → 정답 공개 → 다음 | 정답 +10, 빨리 낸 순 최대 +5 |
| 퀴즈 단답 | 3번까지 입력, 공백·문장부호·영문 대소문자 무시 | 정답 +10, 1·2·3등 추가 +10/+6/+3 |
| 서바이벌 퀴즈 | 틀리면 감옥, 첫 문제에 답한 사람만 참가, 전원 탈락이면 그 문제 무효 | 문제마다 생존 +5, 우승 +30 |
| 가위바위보 | 강사 손(가위·바위·보·랜덤) 공개, 지거나 안 내면 감옥 | 판마다 생존 +5, 우승 +30 |
| 달리기 | 3·2·1·GO, 폰의 [달려!] 연타(초당 8걸음까지 인정), 목표 걸음·제한 시간 설정 | 1·2·3등 +30/+20/+10, 완주 +5 |

- 모든 게임: 참가만 해도 +2.
- 동점이면 정답 수 → 평균 응답 시간 → 먼저 참가한 사람.
- 점수 숫자는 게임 탭 **⚙️ 점수 규칙**에서 바꿀 수 있습니다(다음에 시작하는 게임부터, 이 PC 에 기억).

### 퀴즈 한 줄 형식

게임 탭 글 상자에 **한 줄에 한 문제**. `.txt` 로 내보내기·불러오기, [저장]하면 이 PC 에 남습니다.

```
OX | 지구는 태양 주위를 돈다 | O
객관식 | 우리나라 수도는? | 서울, 부산, 대구, 광주 | 1
단답 | 세종대왕이 만든 글자는? | 한글, 훈민정음
OX | 고래는 물고기다 | X | 20초
```

- 객관식: 보기는 쉼표로 2~4개, 마지막 칸이 정답 번호(1부터).
- 단답: 정답이 여러 개면 쉼표로.
- 끝에 `| 20초` 를 붙이면 제한 시간 변경(5~120초, 기본 OX 10초 · 객관식 15초 · 단답 20초).
- `#` 으로 시작하는 줄은 메모(문제로 안 읽음).
- 틀린 줄은 줄 번호와 이유가 아래에 표시되고, 나머지 줄은 그대로 쓰입니다.

## 로컬 실행

```bash
npm install --legacy-peer-deps
npm run dev
```

→ http://localhost:3030

## Supabase 설정

`.env.local` 파일:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
```

1주일 안 쓰면 Supabase 무료 프로젝트가 멈춥니다 — 연수 전날 한 번 열어 깨워 두세요.

### 게임 결과 DB 저장 (선택)

끝난 게임을 DB 에 저장해 다른 PC 에서 종합 순위를 복원합니다. 켜기 전에는 결과가 발표 PC 브라우저에만 남습니다(CSV 는 그대로 됨).

1. `supabase/migrations/20261016000000_game_results.sql` 을 운영 DB 에 적용
2. Vercel 환경 변수 `LL_RESULTS_DB=1`
3. 재배포

순서를 지켜야 합니다 — 1 없이 2를 켜면 저장이 조용히 실패합니다.

## 시험

```bash
npx tsc --noEmit
npm test                         # 단위(채점·순위·CSV·해시)
node tests/p4-db.mjs             # 마이그레이션 SQL (메모리 Postgres)
npm run build && npx next start --port 3030
node tests/regression.mjs        # 기존 기능 회귀
node tests/p3-e2e.mjs            # 폰 3대 게임 5종
N=40 node tests/p1-load.mjs      # 가짜 40명 통신량
LL_RESULTS_DB=1 npx next start --port 3031 && BASE=http://localhost:3031 node tests/p4-e2e.mjs   # 순위·CSV·DB 복원
```

e2e 는 Playwright(크롬)와 실제 Supabase 를 씁니다.
